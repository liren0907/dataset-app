# Fabric Annotator 功能說明文件 (Features Documentation)

本文件詳列了 `Fabric Annotator` 頁面中的各項功能，旨在提供專業標註流程的完整功能清單。

## 功能列表

| 分類 | 功能名稱 | 說明 | 快捷鍵 / 操作 |
| :--- | :--- | :--- | :--- |
| **標註工具 (Toolbar)** | 選取 (Select) | 選擇並移動畫布上的標註物件 | `V` |
| | 矩形框 (BBox) | 繪製矩形邊框標註物件 | `R` |
| | 多邊形 (Polygon) | 繪製不規則多邊形標註物件 | `P` |
| | 折線 (Polyline) | 繪製線條標註（如車道線標註） | `L` |
| | 關鍵點 (Keypoint) | 繪製點位標註（如人臉特徵點） | `K` |
| | 平移 (Pan) | 拖動查看畫布不同區域 | `H` |
| **資料管理 (Data)** | 載入圖片 (Load Image) | 從本地選擇單張圖片進行標註 | 點擊標題右側按鈕 |
| | 載入目錄 (Load Dir) | 選取整個資料夾，批次標註多張圖片 | 點擊標題右側按鈕 |
| | 模擬數據 (Mock) | 載入範例數據用於功能測試 | 點擊標題右側按鈕 |
| **畫布互動 (Canvas)** | 撤銷 / 重做 | 復原或取消復原先前的標註操作 | `Ctrl/Cmd + Z` / `+ Shift` |
| | 縮放與平移 | 使用滑鼠滾輪縮放；選取平移工具後拖拽 | 滾輪 / 拖拽 |
| | 頂點編輯 | 選取多邊形後，可拖拽個別頂點進行細微調整 | 選取物件後操作 |
| **側邊欄 (Outliner)** | 摺疊介面 | 隱藏左側畫廊或右側資訊欄以極大化畫布 | 點擊兩側隱藏箭頭 |
| | 物件清單 | 顯示當前圖片中所有標註物件與對應類別 | 右側清單顯示 |
| | 鎖定 (Lock) | 鎖定物件防止誤觸移動 | 清單中點擊 `lock_open` |
| | 隱藏 (Hide) | 暫時隱藏畫布上的特定標註以利查看 | 清單中點擊 `visibility` |
| **屬性編輯 (Inspector)** | 坐標編輯 | 手動輸入 X, Y, W, H 值進行精確調整 | 右下角面板 |
| | 批次標籤 (Batch) | 同時選取多個物件時，可一鍵修改所有物件的標籤 | 多選後使用下拉選單 |
| **統計與監控** | 統計看板 (Stats) | 查看當前進度、標註總數及各類別的分佈比例 | 右下角 `bar_chart` 圖示 |
| | 狀態管理 | 標記圖片為「未標註」、「標註中」或「完成」 | 標註過程自動切換 |

## 快速提示 (Quick Tips)

1. **快速標籤**：選取物件後按數字鍵 `1-9` 可快速指定預設的類別標籤。
2. **多選操作**：在畫布上按住 `Shift` 加選物件，或直接框選多個物件，即可啟用「批次動作」。
3. **完成繪圖**：繪製多邊形或折線時，點擊右上方出現的「綠色勾勾」或按 `Enter` 即可完成。
